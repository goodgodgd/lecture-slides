로봇공학 · 14회 · 2부 C++

람다·const·C++17 — AI에게 명세를 주는 법

오늘 답할 질문
  1. [lo, hi](float r) { ... } 처럼 생긴 것은 대체 무엇인가?
  2. 대괄호 안에 [=]를 쓰면 왜 위험한가? [&]는 안전한가?
  3. 500ms라고 쓰는 것과 500이라고 쓰는 것은 무엇이 다른가?
  4. "값이 없다"를 -1로 표현하면 무엇이 잘못되나?
  5. AI에게 더 나은 코드를 받아내려면 요구를 어떻게 바꿔야 하나?

2부의 마지막이다. 오늘 배우는 것들은 서로 달라 보이지만 하나로 묶인다 — 전부 "내 의도를 코드에 적어 두는 방법"이다.

const는 "이 함수는 상태를 안 바꾼다"는 약속이고, std::optional은 "값이 없을 수도 있다"는 경고이고, 500ms는 "이건 밀리초다"라는 표시다. 셋 다 주석이 아니라 코드로 적는다. 그래서 컴파일러가 검사해 준다.

그리고 이것이 이 강의의 결론과 이어진다. AI에게 잘 시키는 법은 결국 명세를 잘 쓰는 법이다. "효율적으로 짜 줘"는 명세가 아니다. "실패할 수 있는 함수는 std::optional로 반환해 줘"는 명세다.

오늘도 프로그램 하나를 들고 간다. driver.cpp — 라이다 값 다섯 개를 받아 가까운 것을 세고 가장 가까운 것을 찾는 Driver다. 처음에는 AI가 준 그대로의 스무 줄짜리이고, 절이 넘어갈 때마다 한 군데를 고치거나 몇 줄을 더한다. ⑦절이 끝나면 오늘 배운 여덟 가지가 전부 들어 있는 완성본이 된다.

  • 본문에는 그 절에서 새로 넣거나 고친 줄만 보인다. 초록 바탕이 새 줄, 붉은 취소선이 지운 줄이다.
  • 그 아래 📄 「전체 코드」 상자를 누르면 그 단계까지의 파일 전체가 나온다. 어느 단계를 펼쳐도 그대로 빌드되고 돌아간다. 오른쪽 위 「복사」로 통째로 가져갈 수 있다.
  • 컴파일 오류나 이상한 값을 보여 주는 자리는 한 글자만 바꾼 「변형」 파일을 따로 접어 뒀다. 그것도 전체 파일이다.
  • 「실제로 나온 출력」에는 그 절이 새로 찍는 줄만 보인다. 전체 출력은 실습 「성공 화면」에 있다.

한 장 요약 — 학기가 끝나도 이 표만 남으면 된다

무엇을 먼저 볼지: 오른쪽 「무엇을 막아 주나」 열이다. 왼쪽은 그 수단일 뿐이다.

이걸 쓴다무슨 뜻인가무엇을 막아 주나수준
[this] 캡처이 객체의 멤버를 쓴다무엇을 쓰는지 코드에 드러난다[요구]
[&x] 캡처x만 원본을 가리킨다필요 없는 것까지 끌고 오지 않는다[요구]
[=] 캡처 🔴바깥의 모든 것을 복사한다— 큰 것이 통째로 복사된다[판단]
500ms500밀리초짜리 시간 값초인지 밀리초인지 헷갈리는 것[요구]
const 멤버 함수이 함수는 상태를 안 바꾼다실수로 멤버를 고치는 것 — 컴파일이 막는다[요구]
std::optional<T>값이 있을 수도, 없을 수도-1을 거리로 읽는 것[요구]
구조적 바인딩 auto [x, y]묶여 온 값을 한 줄로 푼다.first·.second를 헷갈리는 것[판단]
if (auto p = ...; ...)이 if 안에서만 사는 변수이름이 밖으로 새는 것[알아보기]
해석: 세 번째 줄만 🔴다. [=]는 쓰지 말라는 뜻이 아니라 "왜 [=]인지 말할 수 있어야 한다"는 뜻이다. 실제로 오늘 함정 상자에서는 [=]가 맞는 답인 경우가 나온다. 나머지 일곱 줄은 전부 AI에게 그대로 요구할 수 있는 것들이다.

① 이름 없는 함수를 그 자리에서 만드는 것이 람다다 🟡 맡기되 검사

언제 이게 필요해지나

표준 알고리즘에 조건을 넘겨야 할 때가 있다. "거리 범위 안에 들어오는 것만 세어 줘"라고 하려면 그 「범위 안에 들어오는가」를 어딘가에 적어야 한다. 함수를 하나 따로 만들 수도 있다.

1단계 — AI가 준 그대로의 출발점

"라이다 값 중 쓸 만한 것이 몇 개인지 세어 줘"라고 하면 흔히 이런 모양이 온다.

함수를 따로 만들면 이렇게 된다 🔴
float g_lo = 0.16f;                 // 함수 밖에 값을 꺼내 놔야 한다
float g_hi = 8.0f;

bool is_valid(float r) { return r >= g_lo && r <= g_hi; }

int main()
{
  const std::vector<float> ranges{0.83f, 0.42f, 1.24f, 0.31f, 2.05f};   // 라이다 값 다섯 개

  std::printf("① 람다 — 조건을 그 자리에서 적는다\n");
  const int n = static_cast<int>(std::count_if(ranges.begin(), ranges.end(), is_valid));
  std::printf("   쓸 만한 값: %d개\n", n);
  return 0;
}

조건 하나 때문에 함수 하나와 전역 변수 둘이 생겼다. 조건을 확인하려면 위로 스크롤해서 is_valid를 찾아야 한다. 그리고 g_lo는 아무나 고칠 수 있다.

float g_lo = 0.16f;                 // 함수 밖에 값을 꺼내 놔야 한다
float g_hi = 8.0f;
bool is_valid(float r) { return r >= g_lo && r <= g_hi; }

  auto is_close = [](float r) { return r < 0.5f; };   // 이름을 붙여 둔 람다
  std::printf("   is_close(0.42) = %s,  is_close(1.24) = %s\n\n",
              is_close(0.42f) ? "참" : "거짓", is_close(1.24f) ? "참" : "거짓");
  return 0;
}

🆕 이 코드에서 처음 나오는 것

[lo, hi](float r) { return ...; }
이름 없이 그 자리에서 만드는 작은 함수다. 세 칸으로 나뉜다 — 대괄호(바깥에서 무엇을 가져올지), 괄호(무엇을 받을지), 중괄호(무엇을 할지). 여기서는 "값 하나를 받아 범위 안인지 참·거짓으로 답하는" 함수를 만들었다.
auto is_close = [](float r) { return r < 0.5f; };
만든 람다에 이름을 붙여 둘 수도 있다. 그러면 보통 함수처럼 is_close(0.42f)로 부른다. 타입 이름을 적을 수 없으므로 auto로만 받을 수 있다.

쓸 때 / 안 쓸 때

이렇게 한다언제
람다를 그 자리에 쓴다기본값. 그 조건을 한 군데서만 쓸 때
람다에 이름을 붙인다 (auto f = ...)같은 조건을 한 함수 안에서 두세 번 쓸 때
보통 함수로 뺀다여러 파일에서 쓰거나, 조건이 열 줄을 넘어갈 때
해석: 판단 기준은 「이 조건을 몇 군데서 쓰나」 하나다. 한 군데면 람다, 여러 군데면 함수. 길이는 그다음 문제다.
이 조건을 여러 군데서 쓰고 있으면 이름 붙인 함수로 빼 주고, 한 군데서만 쓰면 그 자리에 람다로 남겨 줘. 어느 쪽을 골랐는지 한 줄로 알려 줘.

② 대괄호 안에 무엇을 적느냐가 이 회차의 알맹이다 🔴 사람이 판단

대괄호를 캡처(capture)라고 부른다. "바깥에 있는 것 중 무엇을 가져다 쓸지" 적는 칸이다. 네 가지가 있고, AI는 거의 항상 넷 중 하나를 습관적으로 고른다.

무엇을 먼저 볼지: 맨 아래 두 줄이다. [&]와 [=]는 "바깥 전부"라는 점이 같고, 원본을 가리키느냐 복사하느냐만 다르다.

적는 것무엇을 가져오나이럴 때 쓴다
[this]이 객체의 멤버를 쓴다멤버 하나를 쓸 때. 콜백의 기본값
[&x]x 만 원본을 가리킨다무엇을 쓰는지 코드에 드러난다
[&]바깥의 모든 것을 원본으로편하지만 무엇을 쓰는지 안 보인다
[=]바깥의 모든 것을 복사로큰 것이 통째로 복사된다

3단계 — 값과 문턱을 클래스로 옮긴다. 람다가 멤버를 쓰게 된다

ROS 2 노드는 클래스다(8회). 문턱값 limit_도 거리 값 ranges_도 멤버가 된다. 그러면 람다는 바깥 변수가 아니라 멤버를 써야 하고, 그 자리에 [this]가 온다. main 위에 클래스를 하나 넣는다. 

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), ranges_(ranges) {}

  // [this] — 이 객체의 멤버를 쓰겠다
  int close_count_this()
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [this](float r) { return r < limit_; }));
  }

  // [&] — 바깥의 모든 것을 참조로 가져다 쓰겠다 (편하지만 무엇을 쓰는지 안 보인다)
  int close_count_amp()
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [&](float r) { return r < limit_; }));
  }

private:
  float limit_;                  // 「가깝다」의 문턱
  std::vector<float> ranges_;
};

그리고 main에서 2단계의 ranges를 넘겨 하나 만들고 두 함수를 부른다.

  // … 2단계까지의 줄은 그대로 …

              d.close_count_amp());
  return 0;

#include <algorithm>
#include <cstdio>
#include <vector>

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), ranges_(ranges) {}

  // [this] — 이 객체의 멤버를 쓰겠다
  int close_count_this()
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [this](float r) { return r < limit_; }));
  }

  // [&] — 바깥의 모든 것을 참조로 가져다 쓰겠다 (편하지만 무엇을 쓰는지 안 보인다)

  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [&](float r) { return r < limit_; }));
  }

private:
  float limit_;                  // 「가깝다」의 문턱
  std::vector<float> ranges_;
};

{

  std::printf("② 캡처 — 바깥 변수를 무엇으로 가져오나\n");
  Driver d(ranges);
  std::printf("   [this] 로 센 것: %d개\n", d.close_count_this());

해석: 결과가 같은데도 [this]가 나은 이유는 읽는 사람 때문이다. [&]는 "뭔가 바깥 것을 쓴다"까지만 알려 주고, 무엇을 쓰는지는 중괄호 안을 다 읽어야 안다. 람다가 스무 줄이 되면 그 차이가 커진다.

[=]는 "바깥의 모든 것을 값으로 가져온다"는 뜻이다. 값으로 가져온다는 것은 복사한다는 뜻이다. Driver에 복사 생성자를 넣고 그 안에서 세어 봤다 — 11회에서 복사 횟수를 세던 방법 그대로다.

// 14회 — 람다·const·C++17: 라이다 값을 거르는 Driver 를 단계별로 키운다
#include <algorithm>
#include <cstdio>
#include <vector>

int g_copies = 0;                   // Driver 가 복사된 횟수. 11회에서 복사를 세던 방법 그대로다

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), ranges_(ranges) {}
  Driver(const Driver & o) : limit_(o.limit_), ranges_(o.ranges_) { ++g_copies; }   // 복사될 때마다 센다

  // [this] — 이 객체의 멤버를 쓰겠다
  int close_count_this()
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [this](float r) { return r < limit_; }));
  }

  // [&] — 바깥의 모든 것을 참조로 가져다 쓰겠다 (편하지만 무엇을 쓰는지 안 보인다)
  int close_count_amp()
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [&](float r) { return r < limit_; }));
  }

  int size() const { return static_cast<int>(ranges_.size()); }

private:
  float limit_;                  // 「가깝다」의 문턱
  std::vector<float> ranges_;
};

int main()
{
  const std::vector<float> ranges{0.83f, 0.42f, 1.24f, 0.31f, 2.05f};   // 라이다 값 다섯 개

  std::printf("① 람다 — 조건을 그 자리에서 적는다\n");
  const float lo = 0.16f, hi = 8.0f;
  const int n = static_cast<int>(
    std::count_if(ranges.begin(), ranges.end(),
                  [lo, hi](float r) { return r >= lo && r <= hi; }));
  std::printf("   쓸 만한 값: %d개\n", n);

  auto is_close = [](float r) { return r < 0.5f; };   // 이름을 붙여 둔 람다
  std::printf("   is_close(0.42) = %s,  is_close(1.24) = %s\n\n",
              is_close(0.42f) ? "참" : "거짓", is_close(1.24f) ? "참" : "거짓");

  std::printf("② 캡처 — 바깥 변수를 무엇으로 가져오나\n");
  Driver d(ranges);
  std::printf("   [this] 로 센 것: %d개\n", d.close_count_this());
  std::printf("   [&]    로 센 것: %d개   (결과는 같지만 무엇을 쓰는지 안 보인다)\n\n",
              d.close_count_amp());

  std::printf("② [=] 는 값으로 복사한다 — 큰 것이 통째로 복사된다\n");
  g_copies = 0;
  auto by_copy = [=]() { return d.size(); };      // 여기서 Driver 가 통째로 복사된다
  std::printf("   [=]  로 캡처한 순간 Driver 복사 %d회 (ranges %d칸)\n", g_copies, by_copy());
  g_copies = 0;
  auto by_ref = [&d]() { return d.size(); };
  std::printf("   [&d] 로 캡처하면 복사 %d회 (ranges %d칸)\n\n", g_copies, by_ref());
  return 0;
}

람다가 어디에 사나무엇으로 캡처하나
그 자리에서 만들어 그 자리에서 쓰고 버린다 (count_if에 넘기는 것)[&x]나 [this] — 복사가 필요 없다
저장해 뒀다가 나중에 부른다 (콜백, 타이머, std::function 멤버)값으로 캡처한다. 가리키던 것이 먼저 사라질 수 있다

AI는 이 구분을 잘 못한다. 두 경우에 똑같이 [&]나 [=]를 쓴다. 받은 코드에서 람다가 어디에 저장되는지를 먼저 보고 판단해야 한다.

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), ranges_(ranges) {}
  Driver(const Driver & o) : limit_(o.limit_), ranges_(o.ranges_) { ++g_copies; }   // 복사될 때마다 센다

                    [&](float r) { return r < limit_; }));
  }

  int size() const { return static_cast<int>(ranges_.size()); }

private:
  float limit_;                  // 「가깝다」의 문턱

④ const 멤버 함수는 AI에게 주는 명세다 🟡 맡기되 검사

int g_copies = 0;                   // Driver 가 복사된 횟수. 11회에서 복사를 세던 방법 그대로다

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), hits_(0), ranges_(ranges) {}
  Driver(const Driver & o) : limit_(o.limit_), hits_(o.hits_), ranges_(o.ranges_) { ++g_copies; }   // 복사될 때마다 센다

  // [this] — 이 객체의 멤버를 쓰겠다
  int close_count_this() const
  {
    ++hits_;                    // ← 읽기만 하는 함수에서 상태를 바꾸려 한다
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [this](float r) { return r < limit_; }));

  {

      std::count_if(ranges_.begin(), ranges_.end(),
                    [&](float r) { return r < limit_; }));
  }

  int size() const { return static_cast<int>(ranges_.size()); }

  void record() { hits_ += close_count_this(); }   // 상태를 바꾸는 함수 — const 가 없다
  int hits() const { return hits_; }

private:

해석: 이 오류를 만나면 둘 중 하나다 — ① 그 함수에 const를 붙였어야 하는데 안 붙였다 (대개 이쪽이다) ② 정말로 상태를 바꿔야 하는데 const 객체로 받았다. 먼저 ①을 의심하라. AI는 읽기만 하는 함수에도 const를 자주 빠뜨린다.
이 클래스에서 상태를 바꾸지 않는 멤버 함수에 전부 const를 붙여 줘. 붙일 수 없는 함수가 있으면 왜인지 알려 줘.

// 14회 — 람다·const·C++17: 라이다 값을 거르는 Driver 를 단계별로 키운다
#include <algorithm>
#include <chrono>
#include <cmath>
#include <cstdio>
#include <functional>
#include <iterator>
#include <optional>
#include <vector>

using namespace std::chrono_literals;   // 500ms 같은 표기를 쓰게 해 준다

int g_copies = 0;                   // Driver 가 복사된 횟수. 11회에서 복사를 세던 방법 그대로다

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), hits_(0), ranges_(ranges) {}
  Driver(const Driver & o) : limit_(o.limit_), hits_(o.hits_), ranges_(o.ranges_) { ++g_copies; }   // 복사될 때마다 센다

  // [this] — 이 객체의 멤버를 쓰겠다
  int close_count_this() const
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [this](float r) { return r < limit_; }));
  }

  // [&] — 바깥의 모든 것을 참조로 가져다 쓰겠다 (편하지만 무엇을 쓰는지 안 보인다)
  int close_count_amp() const
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [&](float r) { return r < limit_; }));
  }

  int size() const { return static_cast<int>(ranges_.size()); }

  void record() { hits_ += close_count_this(); }   // 상태를 바꾸는 함수 — const 가 없다
  int hits() const { return hits_; }

  // 쓸 만한 값 중 가장 가까운 것. 하나도 없으면 「값 없음」을 돌려주고 기록을 남긴다
  std::optional<float> nearest() const
  {
    const float lo = 0.16f, hi = 8.0f;
    std::vector<float> good;
    std::copy_if(ranges_.begin(), ranges_.end(), std::back_inserter(good),
                 [lo, hi](float r) { return std::isfinite(r) && r >= lo && r <= hi; });
    if (good.empty()) {
      std::fprintf(stderr, "[warn] Driver::nearest: 쓸 만한 거리 값이 하나도 없다\n");
      return std::nullopt;
    }
    return *std::min_element(good.begin(), good.end());
  }

private:
  float limit_;                  // 「가깝다」의 문턱
  int hits_;                     // record() 가 불린 만큼 쌓인다
  std::vector<float> ranges_;
};

// 「나중에 부를 함수」를 돌려준다
std::function<float()> make_reader()
{
  std::vector<float> ranges{0.83f, 0.42f, 1.24f};   // 이 함수 안에서만 사는 값
  return [ranges]() { return ranges.at(0); };      // 복사해서 들고 나간다
}

int main()
{
  const std::vector<float> ranges{0.83f, 0.42f, 1.24f, 0.31f, 2.05f};   // 라이다 값 다섯 개

  std::printf("① 람다 — 조건을 그 자리에서 적는다\n");
  const float lo = 0.16f, hi = 8.0f;
  const int n = static_cast<int>(
    std::count_if(ranges.begin(), ranges.end(),
                  [lo, hi](float r) { return r >= lo && r <= hi; }));
  std::printf("   쓸 만한 값: %d개\n", n);

  auto is_close = [](float r) { return r < 0.5f; };   // 이름을 붙여 둔 람다
  std::printf("   is_close(0.42) = %s,  is_close(1.24) = %s\n\n",
              is_close(0.42f) ? "참" : "거짓", is_close(1.24f) ? "참" : "거짓");

  std::printf("② 캡처 — 바깥 변수를 무엇으로 가져오나\n");
  Driver d(ranges);
  std::printf("   [this] 로 센 것: %d개\n", d.close_count_this());
  std::printf("   [&]    로 센 것: %d개   (결과는 같지만 무엇을 쓰는지 안 보인다)\n\n",
              d.close_count_amp());

  std::printf("② [=] 는 값으로 복사한다 — 큰 것이 통째로 복사된다\n");
  g_copies = 0;
  auto by_copy = [=]() { return d.size(); };      // 여기서 Driver 가 통째로 복사된다
  std::printf("   [=]  로 캡처한 순간 Driver 복사 %d회 (ranges %d칸)\n", g_copies, by_copy());
  g_copies = 0;
  auto by_ref = [&d]() { return d.size(); };
  std::printf("   [&d] 로 캡처하면 복사 %d회 (ranges %d칸)\n\n", g_copies, by_ref());

  std::printf("⚠️ 저장해 뒀다 나중에 부르는 람다\n");
  auto read = make_reader();      // make_reader 는 이미 끝났다. 그 안의 ranges 도 사라졌다
  std::printf("   읽은 값: %.2f\n\n", read());

  std::printf("③ 500ms — 단위가 코드에 적혀 있다\n");

  std::printf("④ const — 이 함수는 상태를 바꾸지 않는다\n");
  std::printf("   close_count_this() = %d  (상태는 그대로, hits = %d)\n", d.close_count_this(), d.hits());
  d.record();
  std::printf("   record() 한 뒤 hits = %d\n", d.hits());
  const Driver frozen(ranges);
  std::printf("   const 객체에서도 close_count_this 는 부를 수 있다: %d\n", frozen.close_count_this());
  std::printf("   frozen.record() 는 컴파일이 안 된다 — 상태를 바꾸는 함수이기 때문이다\n\n");

  std::printf("⑥ optional — \"값이 없음\"을 -1 로 표현하지 않는다\n");
  const Driver blind({INFINITY, std::nanf(""), 99.0f});   // 전부 못 쓰는 값 — 아무것도 없는 방향
  const auto near = d.nearest();
  const auto none = blind.nearest();
  std::printf("   d.nearest()     : %s\n", near.has_value() ? "값 있음" : "값 없음(nullopt)");
  std::printf("   blind.nearest() : %s\n", none.has_value() ? "값 있음" : "값 없음(nullopt)");
  if (!none) { std::printf("   → if (!v) 한 줄로 걸러진다. 검사를 빠뜨리기 어렵다\n"); }
  if (near)  { std::printf("   → 값이 있을 때만 꺼낸다: *near = %.2f\n\n", *near); }
  return 0;
}

class Driver {
public:
  Driver(const std::vector<float> & ranges) : limit_(0.5f), hits_(0), ranges_(ranges) {}
  Driver(const Driver & o) : limit_(o.limit_), hits_(o.hits_), ranges_(o.ranges_) { ++g_copies; }   // 복사될 때마다 센다

  // [this] — 이 객체의 멤버를 쓰겠다
  int close_count_this() const
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [this](float r) { return r < limit_; }));
  }

  // [&] — 바깥의 모든 것을 참조로 가져다 쓰겠다 (편하지만 무엇을 쓰는지 안 보인다)
  int close_count_amp() const
  {
    return static_cast<int>(
      std::count_if(ranges_.begin(), ranges_.end(),
                    [&](float r) { return r < limit_; }));
  }

  int size() const { return static_cast<int>(ranges_.size()); }

  void record() { hits_ += close_count_this(); }   // 상태를 바꾸는 함수 — const 가 없다
  int hits() const { return hits_; }

  // 쓸 만한 값 중 가장 가까운 것. 하나도 없으면 「값 없음」을 돌려주고 기록을 남긴다
  std::optional<float> nearest() const
  {
    const float lo = 0.16f, hi = 8.0f;
    std::vector<float> good;
    std::copy_if(ranges_.begin(), ranges_.end(), std::back_inserter(good),
                 [lo, hi](float r) { return std::isfinite(r) && r >= lo && r <= hi; });
    if (good.empty()) {
      std::fprintf(stderr, "[warn] Driver::nearest: 쓸 만한 거리 값이 하나도 없다\n");
      return std::nullopt;
    }
    return *std::min_element(good.begin(), good.end());
  }

private:
  float limit_;                  // 「가깝다」의 문턱
  int hits_;                     // record() 가 불린 만큼 쌓인다
  std::vector<float> ranges_;
};

// 「나중에 부를 함수」를 돌려준다
std::function<float()> make_reader()
{
  std::vector<float> ranges{0.83f, 0.42f, 1.24f};   // 이 함수 안에서만 사는 값
  return [ranges]() { return ranges.at(0); };      // 복사해서 들고 나간다
}

// 극좌표(거리 r, 각도 th) → 직교좌표(x, y). 값 두 개를 묶어서 돌려준다
std::pair<float, float> to_xy(float r, float th) { return {r * std::cos(th), r * std::sin(th)}; }

int main()
{
  const std::vector<float> ranges{0.83f, 0.42f, 1.24f, 0.31f, 2.05f};   // 라이다 값 다섯 개

  std::printf("① 람다 — 조건을 그 자리에서 적는다\n");
  const float lo = 0.16f, hi = 8.0f;
  const int n = static_cast<int>(
    std::count_if(ranges.begin(), ranges.end(),
                  [lo, hi](float r) { return r >= lo && r <= hi; }));
  std::printf("   쓸 만한 값: %d개\n", n);

  auto is_close = [](float r) { return r < 0.5f; };   // 이름을 붙여 둔 람다
  std::printf("   is_close(0.42) = %s,  is_close(1.24) = %s\n\n",
              is_close(0.42f) ? "참" : "거짓", is_close(1.24f) ? "참" : "거짓");

  std::printf("② 캡처 — 바깥 변수를 무엇으로 가져오나\n");
  Driver d(ranges);
  std::printf("   [this] 로 센 것: %d개\n", d.close_count_this());
  std::printf("   [&]    로 센 것: %d개   (결과는 같지만 무엇을 쓰는지 안 보인다)\n\n",
              d.close_count_amp());

  std::printf("② [=] 는 값으로 복사한다 — 큰 것이 통째로 복사된다\n");
  g_copies = 0;
  auto by_copy = [=]() { return d.size(); };      // 여기서 Driver 가 통째로 복사된다
  std::printf("   [=]  로 캡처한 순간 Driver 복사 %d회 (ranges %d칸)\n", g_copies, by_copy());
  g_copies = 0;
  auto by_ref = [&d]() { return d.size(); };
  std::printf("   [&d] 로 캡처하면 복사 %d회 (ranges %d칸)\n\n", g_copies, by_ref());

  std::printf("⚠️ 저장해 뒀다 나중에 부르는 람다\n");
  auto read = make_reader();      // make_reader 는 이미 끝났다. 그 안의 ranges 도 사라졌다
  std::printf("   읽은 값: %.2f\n\n", read());

  std::printf("③ 500ms — 단위가 코드에 적혀 있다\n");
  const auto period = 500ms;      // 스캔 하나를 이만큼마다 받는다고 하자
  std::printf("   500ms 는 %ld 밀리초짜리 시간 값이다\n",
              std::chrono::duration_cast<std::chrono::milliseconds>(period).count());
  std::printf("   0.5 라고 쓰면 초인지 밀리초인지 코드만 봐서는 알 수 없다\n\n");

  std::printf("④ const — 이 함수는 상태를 바꾸지 않는다\n");
  std::printf("   close_count_this() = %d  (상태는 그대로, hits = %d)\n", d.close_count_this(), d.hits());
  d.record();
  std::printf("   record() 한 뒤 hits = %d\n", d.hits());
  const Driver frozen(ranges);
  std::printf("   const 객체에서도 close_count_this 는 부를 수 있다: %d\n", frozen.close_count_this());
  std::printf("   frozen.record() 는 컴파일이 안 된다 — 상태를 바꾸는 함수이기 때문이다\n\n");

  std::printf("⑥ optional — \"값이 없음\"을 -1 로 표현하지 않는다\n");
  const Driver blind({INFINITY, std::nanf(""), 99.0f});   // 전부 못 쓰는 값 — 아무것도 없는 방향
  const auto near = d.nearest();
  const auto none = blind.nearest();
  std::printf("   d.nearest()     : %s\n", near.has_value() ? "값 있음" : "값 없음(nullopt)");
  std::printf("   blind.nearest() : %s\n", none.has_value() ? "값 있음" : "값 없음(nullopt)");
  if (!none) { std::printf("   → if (!v) 한 줄로 걸러진다. 검사를 빠뜨리기 어렵다\n"); }
  if (near)  { std::printf("   → 값이 있을 때만 꺼낸다: *near = %.2f\n\n", *near); }

  std::printf("⑦ 구조적 바인딩 — 묶여 온 값을 한 줄로 푼다\n");
  const auto [x, y] = to_xy(*near, 0.5236f);          // 가장 가까운 값이 30° 방향에 있다고 하자
  std::printf("   r=%.2f m, θ=30° → x=%.3f, y=%.3f\n\n", *near, x, y);

  std::printf("⑦ if 안 선언 — 그 변수는 if 밖으로 새지 않는다\n");
  if (auto it = std::find_if(ranges.begin(), ranges.end(), is_close);
      it != ranges.end())
  {
    std::printf("   0.5m 안쪽 값 %.2f 를 먼저 찾았다\n", *it);
  }
  std::printf("   여기서는 it 를 쓸 수 없다 — 이름이 새지 않으니 다음 if 에서 또 쓸 수 있다\n");
  return 0;
}

📝 HW4 — 프롬프트를 고쳐 더 나은 코드를 받아낸다 🔴 사람이 한다

같은 요구를 세 번 다르게 해서 받은 코드 셋과, 무엇이 달라졌는지 적는다. 코드를 잘 짜는 것이 아니라 요구를 잘 쓰는 것이 과제다.

제출물무엇을 적나배점
① 처음 요구와 받은 코드막연하게 물어본 것. "라이다 값에서 가장 가까운 거리를 구해 줘" 정도
② 두 번째 요구와 받은 코드"효율적으로 짜 줘" 같은 막연한 개선 요구를 붙인 것
③ 세 번째 요구와 받은 코드무엇이 문제인지 짚은 요구. "inf·NaN을 걸러 줘", "실패하면 optional로 돌려줘", "콜백은 const 참조로 받아 줘"
④ 무엇이 달라졌는지 세 줄 ← 여기가 점수다①→②와 ②→③에서 코드의 어느 줄이 바뀌었나. 바뀐 이유를 자기 말로
⑤ AI가 끝까지 안 고친 것 ← 가점세 번 물어도 안 고쳐진 것이 있으면 그것과 이유가점
해석: ④가 점수인 이유가 있다. 연구에 따르면 막연한 요구("효율적으로 짜 줘")는 효율 점수를 0.294 → 0.342로 올렸지만, 무엇이 문제인지 짚은 요구는 0.385까지 올렸다(만점 1.0 기준, 31% 개선). "더 잘해 줘"는 명세가 아니다. ③에서 그 차이를 직접 만들어 보는 것이 이 과제다.

맨 위에 ---로 감싼 앞머리를 두고 name: cpp-rules와 description:을 넣어 줘. 설명에는 "C++ 코드를 새로 짜거나 고칠 때 적용한다"는 뜻이 들어가야 해.

본문에는 아래 일곱 가지 원칙을 규칙 목록으로 적어 줘. 규칙마다 ① 무엇을 하라 ② 왜 그런지 한 줄 ③ 어기는 코드와 지키는 코드 한 줄씩을 넣어 줘.

1. 큰 값은 const 참조로 받는다
2. new·delete를 직접 쓰지 않고 unique_ptr·shared_ptr를 쓴다
3. 직접 루프를 짜기 전에 STL 알고리즘에 이미 있는지 먼저 찾는다
4. 센서 값처럼 inf·NaN이 섞이는 데이터는 계산 전에 거른다
5. 람다 캡처는 [=]·[&] 대신 필요한 것만 적는다. 저장해 두는 람다는 참조로 캡처하지 않는다
6. 상태를 바꾸지 않는 멤버 함수에는 const를 붙인다
7. 실패할 수 있는 함수는 -1·nullptr 대신 std::optional로 알린다

템플릿을 만드는 법 — 이 과목에서는 만들 일이 없다

std::vector<float>처럼 꺾쇠를 쓰는 일은 매일 있지만, 꺾쇠를 만드는 일은 이 과목에 없다. 그래도 모양은 알아 두면 코드를 읽을 때 덜 놀란다. 아래는 읽기용 조각이다 — driver.cpp에 들어가지 않고, 빌드해 볼 필요도 없다. 

// "어떤 타입이든 받아서 그 타입 그대로 돌려주는" 함수를 만든다
template<typename T>
T clamp_value(T v, T lo, T hi)
{
  if (v < lo) { return lo; }
  if (v > hi) { return hi; }
  return v;
}

// 쓸 때는 타입을 안 적어도 컴파일러가 알아낸다
const float speed = clamp_value(1.2f, 0.0f, 0.22f);   // 0.22f
const int   n     = clamp_value(15, 0, 10);           // 10

template<typename T>는 "아래 함수에서 T는 나중에 정해진다"는 뜻이다. 쓰는 쪽에서 float를 넣으면 float판이, int를 넣으면 int판이 만들어진다. 같은 코드를 타입마다 복사하지 않아도 되는 것이 이득 전부다.

실제로는 위 함수를 만들 필요도 없다. std::clamp가 이미 있다(<algorithm>). 27회에서 속도 명령을 한계 안으로 눌러 줄 때 그걸 쓴다.

템플릿 오류 메시지 읽는 법 — 첫 줄과 마지막 줄만 본다

템플릿을 잘못 쓰면 오류가 수백 줄 나온다. 화면을 가득 채우고 어디부터 봐야 할지 막막하다. 규칙은 간단하다.

어디를 보나무엇이 있나
첫 번째 error: 줄진짜 원인. 여기가 90%다
마지막 몇 줄의 required from here내 코드의 어느 줄에서 시작됐는지
가운데 수백 줄표준 라이브러리 내부 사정. 읽지 않는다

그래도 안 풀리면 첫 error: 줄과 required from here 줄만 잘라서 AI에게 주면 된다. 수백 줄을 통째로 붙이면 오히려 답이 나빠진다.

C++20·C++23이 준 것 — 우리는 C++17을 쓴다

ROS 2 Jazzy는 C++17 기준이다. 아래는 다른 프로젝트에서 봤을 때 알아보기만 하면 되는 것들이다.

무엇어떻게 생겼나무엇이 좋아지나
std::ranges (C++20)std::ranges::sort(v);begin()·end()를 안 쓴다
std::format (C++20)std::format("{:.2f} m", d)printf의 타입 실수가 사라진다
개념(concepts) (C++20)template<std::floating_point T>템플릿 오류가 수백 줄에서 몇 줄로 줄어든다
std::expected (C++23)std::expected<float, Error>optional과 달리 왜 실패했는지도 담는다

마지막 줄이 오늘 배운 optional의 다음 단계다. optional은 "값이 없다"까지만 말하고 왜 없는지는 말하지 못한다. 그래서 실무에서는 optional을 돌려주면서 로그로 이유를 남기는 조합을 쓴다.

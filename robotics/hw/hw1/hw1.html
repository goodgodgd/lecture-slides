리눅스와 git, 내 눈으로 확인하기

📅 제출 마감 — 수업 시간에 공지합니다

이 과제가 묻는 것
  1. 에이전트가 "완료했습니다"라고 했을 때, 무엇을 쳐서 확인했나요?
  2. .bashrc에 분명히 적었는데 그 터미널에서는 값이 안 나옵니다. 왜일까요?
  3. git add를 하면 파일이 어느 칸으로 옮겨 가나요?

왜 이걸 하나요

새로운 것을 배우는 과제가 아닙니다. 수업에서 한 것을 혼자 한 번 더 합니다.

수업에서는 화면을 따라 쳤습니다. 그때는 됩니다. 며칠 뒤에 혼자 치면 다릅니다.

그리고 한 가지가 더 있습니다. 에이전트는 일을 끝내면 "완료했습니다"라고 말합니다. 그 말이 맞는지는 여러분이 무언가를 쳐서 화면을 봐야 알 수 있습니다. 그래서 제출할 것도 결과물이 아니라 여러분이 친 명령과 그때 화면에 나온 것입니다.

에이전트에게 시켜도 됩니다. 다만 시킨 다음에 확인 명령은 여러분이 직접 치고 그 출력을 붙여 넣으세요. 점수가 되는 자리가 거기입니다.

시작하기 전에

파일 이름과 값을 그대로 쓰세요. 그래야 확인 퀴즈에서 같은 것을 물을 수 있습니다. 출력은 고르지 말고 화면에 나온 것을 통째로 붙여 넣으면 됩니다.

🆕 작업 B는 수업에서 만든 저장소를 그대로 씁니다

Git 수업에서 만든 sch-robotics 저장소와 그때 clone한 폴더를 씁니다. 새로 만들지 않습니다. 아직 없으면 그 자료의 「준비」 절부터 보고 먼저 만들어 두세요.

⚠️ 작업 A는 터미널 하나에서, 끝날 때까지 닫지 마세요

중간에 닫거나 새로 열면 A-⑦에서 볼 화면이 달라집니다. 그 장면이 이 과제에서 볼 것 중 하나입니다.

작업 A — 리눅스

#무엇을 합니다
①cd ~/robotics로 들어가 pwd를 칩니다
②echo "hw1 confirm" > hw1.txt 뒤 cat hw1.txt
③echo "second line" >> hw1.txt 뒤 cat hw1.txt
④printf '#!/bin/bash\necho "hello hw1"\n' > run.sh 뒤 ls -l run.sh
⑤./run.sh를 칩니다. 막힙니다. 이어서 echo $?
⑥chmod +x run.sh 뒤 ls -l run.sh와 ./run.sh
⑦~/.bashrc 맨 아래에 export MY_LIDAR=LDS-02를 >>로 넣고, 그 터미널에서 바로 echo "[$MY_LIDAR]"
⑧source ~/.bashrc 뒤 같은 것을 다시 칩니다
⚠️ ⑦에서 >>가 두 개인지 꼭 확인하세요

하나만 치면 .bashrc에 원래 있던 설정이 통째로 지워집니다 (리눅스 자료 ③절).

⑤에서 막히는 것이 정상입니다. 리눅스 자료 ④절에 왜 그런지 있습니다. ⑦에서 빈 줄이 나와도 잘못한 것이 아닙니다. ⑧과 비교해 보세요.

작업 B — git

sch-robotics 폴더에서 합니다. 고치고 → 담고 → 굳히고 → 올리는 한 바퀴를 혼자 돕니다.

#무엇을 합니다
①폴더로 가서 git status를 칩니다
②echo "print('hw1')" > hw1.py 뒤 git status
③git add hw1.py 뒤 git status
④git commit -m "HW1 확인용 hw1.py 추가"
⑤mkdir -p build && echo "binary" > build/out 뒤 git status --short
⑥echo "build/" > .gitignore 뒤 git status --short
⑦git add .gitignore · git commit -m "빌드 결과는 올리지 않는다"
⑧git push origin main
⑨git log --oneline
⑩GitHub 웹 화면을 새로 고치고 파일 목록을 그림으로 남깁니다
⚠️ ②와 ③을 나란히 보세요

같은 파일이 Untracked files에서 Changes to be committed로 옮겨 갑니다. git add가 저장이 아니라 고르는 명령이라는 것이 이 두 화면에 있습니다.

⑤와 ⑥도 나란히 보세요. .gitignore를 만들자 목록이 바뀝니다.

⚠️ ⑧에서 비밀번호를 물으면 토큰을 붙여 넣습니다

Git 자료 ②절에서 만든 토큰입니다. 계정 비밀번호가 아닙니다. 붙여 넣어도 화면에 글자가 안 보이는 것이 정상입니다. 한 번 붙이고 엔터를 치세요.

⑩에서 build 폴더가 없으면 ⑥이 제대로 된 것입니다.

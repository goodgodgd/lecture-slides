라이다로 손을 보고 움직이는 노드

📅 제출 마감 — 2026년 12월 6일 (일) 23:59

이 과제가 묻는 것
  1. 내 로봇을 켜고 /scan을 받아 /cmd_vel로 보내는 노드를 혼자 돌릴 수 있나요?
  2. 「오른쪽 앞」은 라이다 각도로 몇 도에서 몇 도일까요?
  3. 상황이 둘 이상 겹치면 어느 것을 먼저 볼까요?

로봇을 켜고 라이다(/scan)로 손이 어디 있는지 보고, 그에 맞는 속도를 /cmd_vel로 보내는 노드를 만드는 과제입니다. 정면에 손이 있으면 멈추고, 손이 다른 자리에 있으면 여러분이 정한 동작 세 가지 중 하나를 합니다. 프로젝트에서 콘 사이를 달리는 노드도 「라이다로 무엇이 어디 있는지 보고 → 속도를 정해 보낸다」는 같은 뼈대 위에 섭니다.

새로 배우는 것은 없습니다. 24회의 각도 구간 · 중앙값 · TwistStamped, 25회의 ROS 좌표 규약(x 앞 · y 왼쪽 · 반시계 양수)만 씁니다.

시작하기 전에 — 안전

⚠️ 로봇을 받침 위에 올려 바퀴를 띄우고 시작합니다

24회처럼 책 몇 권이나 상자 위에 올려 두 바퀴가 바닥에서 떠 있게 해 둡니다. 바퀴가 도는 방향과 빠르기만 보면 로봇이 어디로 갈지 알 수 있습니다. 바닥에 내려 보는 것은 받침 위에서 다 확인한 뒤에 해도 됩니다.

속도는 이 과목에서 직진 0.1 m/s · 회전 0.5 rad/s 이하를 권합니다. 그리고 터틀봇3는 마지막으로 받은 속도를 계속 유지합니다 — 노드를 Ctrl+C로 꺼도 바퀴가 계속 돌 수 있습니다(24회 ⑦절). 노드를 끈 뒤에는 아래 한 줄로 0을 보냅니다. 

ros2 topic pub --once /cmd_vel geometry_msgs/msg/TwistStamped '{}'

작업 A — 로봇 준비 확인

#터미널무엇을 합니다
①1echo $ROS_DOMAIN_ID — 내 로봇의 번호인지 봅니다(23회)
②1ros2 launch turtlebot3_bringup robot.launch.py — 로봇을 켭니다. 이 터미널은 그대로 둡니다
③2ros2 topic list -t — 목록에 /scan [sensor_msgs/msg/LaserScan]과 /cmd_vel [geometry_msgs/msg/TwistStamped]가 있는지 봅니다

③까지 되면 프로젝트에 필요한 준비는 끝난 것입니다. 안 되면 23회의 「시스템 준비」를 다시 따라가 보세요.

작업 B — 정지와 세 가지 동작

~/ros_ws/src에 패키지 hand_react를 만들고, 실행 파일·노드 이름도 hand_react로 합니다. 가장 쉬운 길은 아래 예시를 그대로 만들어 놓고 고쳐 나가는 것입니다. 노드가 할 일은 넷입니다.

#상황동작
B-1정면에 손이 가까이 있다멈춘다 (직진 0 · 회전 0). 다른 어떤 상황보다 먼저 봅니다
B-2여러분이 정합니다 — 손이 어느 쪽에 얼마나 가까이 있나여러분이 정합니다 — linear.x와 angular.z를 얼마로 보내나
B-3
B-4

B-2~B-4는 서로 다른 자리, 서로 다른 동작이면 됩니다. 예를 들어 「손이 오른쪽 앞에 있으면 왼쪽 앞으로 간다」(예시가 이것입니다 — 셋 중 하나로 써도 됩니다), 「왼쪽에 있으면 제자리에서 오른쪽으로 돈다」, 「뒤에 있으면 앞으로 조금 빨리 간다」 같은 것입니다. 아무 상황에도 해당하지 않을 때 무엇을 할지(천천히 간다 · 선다)도 여러분이 정합니다.

노드는 예시처럼 「{자리} 거리 {거리} m에서 전진속도 {v} m/s, 회전속도 {w} rad/s로 갑니다.」를 1초에 한 번쯤 찍게 합니다. 이 줄을 작업 C에서 그대로 복사해 보고서에 붙입니다.

🆕 「오른쪽 앞」을 각도로 적는 법

라이다의 각도는 0도가 정면이고 반시계 방향(왼쪽)으로 갈수록 커집니다(25회 ROS 좌표 규약). 그래서 왼쪽 앞은 +45도 쪽, 오른쪽 앞은 −45도(= 315도) 쪽, 뒤는 180도 쪽입니다. 아래 예시의 distance_at(scan, 각도)에 그 각도를 넣으면 그 각도 양쪽 10도 구간의 거리(중앙값)가 나옵니다. 회전 속도 angular.z도 같은 규약이라 양수가 왼쪽으로 도는 것입니다.

⚠️ 구간을 손보다 넓게 잡으면 손이 안 보입니다

구간의 거리를 중앙값으로 요약하면(24회 ⑥절), 손이 구간의 절반 이상을 채워야 중앙값이 손의 거리가 됩니다. 20cm 앞의 손은 라이다에서 보면 대략 20~30도를 가립니다. 반폭을 30도(구간 60도)로 잡으면 손이 절반을 못 채워 중앙값은 뒤의 벽 거리가 됩니다. 예시처럼 양쪽 10도쯤에서 시작해 보세요. (교수가 가짜 /scan으로 돌려 확인한 장면입니다.)

⚠️ 라이다에 손을 너무 가까이 대면 거리가 아니라 nan이 됩니다

손바닥을 라이다 바로 앞 몇 cm까지 대면 그 방향은 「가깝다」가 아니라 「못 쟀다」로 나옵니다(24회 🧪 실습 5번). 예시는 구간에 쓸 수 있는 값이 셋도 안 되면 거리를 0으로 보고 섭니다. 그러니 10~25cm쯤에 손을 대고 확인합니다.

예시 — 오른쪽 앞이면 왼쪽 앞으로

/scan이 올 때마다 정면과 우측 전방의 거리를 구하고, if · else if로 속도를 정해 바로 보냅니다. 상황을 더하려면 distance_at으로 그 자리의 거리를 하나 더 구하고 else if를 하나 더 붙이면 됩니다. 로그는 1초에 한 번 「어느 자리의 거리가 얼마여서 어떤 속도로 가는지」를 찍습니다. 

    if (front < 0.30) {                 // B-1 정면에 손 → 멈춘다. 가장 먼저 본다
      v = 0.0;
    } else if (right_front < 0.30) {    // 우측 전방에 손 → 왼쪽 앞으로 간다
      where = "우측 전방";
      dist = right_front;
      w = 0.5;
    }

로그는 아래 줄이 찍습니다. 예시 전체 코드의 on_scan 끝에 있습니다.

    RCLCPP_INFO_THROTTLE(this->get_logger(), *this->get_clock(), 1000,
                         "%s 거리 %.2f m에서 전진속도 %.2f m/s, 회전속도 %.2f rad/s로 갑니다.",
                         where.c_str(), dist, v, w);

🆕 RCLCPP_INFO_THROTTLE — 1초에 한 번만 찍는 로그 (22회 ⑦절)

RCLCPP_INFO_THROTTLE(로거, 시계, 간격ms, "형식", 값…)
RCLCPP_INFO와 같은 로그인데, 이 줄이 지난번에 찍힌 뒤 간격 ms가 안 지났으면 건너뜁니다. /scan은 1초에 열 번쯤 와서 RCLCPP_INFO로 찍으면 화면이 금방 넘칩니다. 여기서는 1000이므로 1초에 한 줄입니다. 속도는 스캔마다 보내고, 찍는 것만 줄인 것입니다.
*this->get_clock()
시간이 얼마나 지났는지 재려면 시계가 필요해서 노드의 시계를 넘깁니다. get_clock()은 시계를 shared_ptr로 돌려주므로 *로 꺼내 넘깁니다.
where.c_str()
%s는 C 문자열을 받으므로 std::string을 .c_str()로 바꿔 넘깁니다.
src/hand_react.cpp — 예시 전체 
// HW6 hand_react — 예시: 정면에 손이 있으면 서고, 오른쪽 앞에 손이 있으면 왼쪽 앞으로 간다
#include <algorithm>
#include <cmath>
#include <memory>
#include <string>
#include <vector>

#include "rclcpp/rclcpp.hpp"
#include "sensor_msgs/msg/laser_scan.hpp"
#include "geometry_msgs/msg/twist_stamped.hpp"

using sensor_msgs::msg::LaserScan;
using geometry_msgs::msg::TwistStamped;

class HandReact : public rclcpp::Node
{
public:
  HandReact()
  : Node("hand_react")
  {
    // 라이다는 best effort 로 보낸다 — 받는 쪽도 센서 데이터용 QoS 로 맞춘다 (22회)
    scan_sub_ = this->create_subscription<LaserScan>(
      "/scan", rclcpp::SensorDataQoS(),
      [this](LaserScan::ConstSharedPtr msg) { on_scan(msg); });
    // 터틀봇3(Jazzy)는 속도 명령을 TwistStamped 로 받는다
    cmd_pub_ = this->create_publisher<TwistStamped>("/cmd_vel", 10);
  }

private:
  // /scan 이 올 때마다(1초에 열 번쯤) 거리를 보고 속도를 정해 보낸다
  void on_scan(LaserScan::ConstSharedPtr msg)
  {
    const double front = distance_at(*msg, 0.0);          // 정면 (0도)
    const double right_front = distance_at(*msg, -45.0);  // 우측 전방 (-45도, 오른쪽은 각도가 음수)

    std::string where = "정면";   // 로그에 찍을 자리와 거리
    double dist = front;
    double v = 0.05;              // 직진 속도 (m/s) — 아무 상황도 아니면 천천히 간다
    double w = 0.0;               // 회전 속도 (rad/s, 양수 = 왼쪽)
    if (front < 0.30) {                 // B-1 정면에 손 → 멈춘다. 가장 먼저 본다
      v = 0.0;
    } else if (right_front < 0.30) {    // 우측 전방에 손 → 왼쪽 앞으로 간다
      where = "우측 전방";
      dist = right_front;
      w = 0.5;
    }

    TwistStamped cmd;                   // 속도 여섯 칸이 전부 0 으로 시작한다
    cmd.header.stamp = this->now();
    cmd.twist.linear.x = v;
    cmd.twist.angular.z = w;
    cmd_pub_->publish(cmd);

    RCLCPP_INFO_THROTTLE(this->get_logger(), *this->get_clock(), 1000,
                         "%s 거리 %.2f m에서 전진속도 %.2f m/s, 회전속도 %.2f rad/s로 갑니다.",
                         where.c_str(), dist, v, w);
  }

  // direction 방향(도)에서 양쪽 10도 구간의 거리 중앙값 (24회).
  // 쓸 수 있는 값이 셋도 안 되면(손이 너무 가까워 nan) 0 을 돌려준다 — 아주 가깝다고 보고 선다
  double distance_at(const LaserScan & scan, double direction) const
  {
    std::vector<float> values;
    for (std::size_t i = 0; i < scan.ranges.size(); ++i) {
      const double deg = (scan.angle_min + i * scan.angle_increment) * 180.0 / M_PI;
      const double diff = std::remainder(deg - direction, 360.0);   // -180 ~ 180 도로 접는다
      const float r = scan.ranges[i];
      if (std::abs(diff) <= 10.0 && std::isfinite(r) && r >= 0.16 && r <= 8.0) {
        values.push_back(r);
      }
    }
    if (values.size() < 3) {
      return 0.0;
    }
    std::sort(values.begin(), values.end());
    return values[values.size() / 2];
  }

  rclcpp::Subscription<LaserScan>::SharedPtr scan_sub_;
  rclcpp::Publisher<TwistStamped>::SharedPtr cmd_pub_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<HandReact>());
  rclcpp::shutdown();
  return 0;
}

AI와의 대화 요약

에이전트와 같이 만들었으면 다른 과제처럼 요약해서 보고서 맨 뒤(D절)에 붙입니다. 세션을 닫기 전에 아래 글을 그대로 보내고, 출력을 고치지 않고 그대로 붙여 넣습니다. 

이 세션을 끝내기 전에 지금까지의 대화를 아래 규칙대로 정리해 줘.
- 내가 보낸 메시지는 요약하지 말고 순서대로 원문 그대로 적어. 한 글자도 바꾸지 마.
- 네 대답은 중간 과정(탐색·시도·되묻기)을 빼고, 그 질문에 실제로 만들거나 고친 것만 두세 줄로 요약해.
  파일을 만들거나 고쳤으면 파일 이름과 무엇을 바꿨는지 적어.
- 대화 순서대로 번호를 붙여 아래 형식으로 써. 이 형식 밖의 말은 붙이지 마.
